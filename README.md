# website

Michael Knapman's Website

This is my professional portfolio attached to my real name, where I publish
interesting code, cool lists, literary ideas.

I want to host the website source code on GitHub so that my content is git
tracked so you can see my projects change over time.

Every git push automatically updates https://michael.nekoweb.org/ thanks
to https://github.com/indiefellas/deploy2nekoweb
Files not able to be pushed by deploy2nekoweb such as the custom cursor
and linter are placed into the "hardcoded" folder.
The "content" folder holds the digital garden as markdown; the build step turns
each file into a webpage under public/.

## Build step

Run this before git add/commit/push to convert `content/*.md` into pages and
inject the fixed left-hand sidebar into every page in `public/`:
    python3 build_site.py

What the build does, in order:
1. Convert the digital-garden source in `content/` into HTML: every
   `content/<path>/<name>.md` becomes `public/<path>/<name>.html`, and each
   folder with articles gets a landing page `public/<folder>.html` that lists
   them (mirroring the `engineering.html` section pattern). Generated pages
   carry a "Generated by build_site.py" marker; the build regenerates them
   from the markdown on every run and prunes generated pages whose source
   markdown has been deleted. Hand-written pages in `public/` (like
   `credits.html`) are never touched.
2. Build the sitemap and inject the sidebar + stylesheet into every page.

The markdown subset is small and intentionally dependency-free: `#` headings,
paragraphs (trailing double spaces become line breaks), `*` bullet items,
pipe tables, and `<https://...>` autolinks. Everything else is HTML-escaped
and passed through verbatim.

Hand-crafted pages: pages you write directly in `public/` (like
`credits.html`, or a pretty art shrine) get the sidebar and stylesheet but
are never overwritten. Add `<!-- nocontentbox -->` anywhere in such a page to
opt out of the cream content-box wrapper so it can control its own layout;
the build unwraps/re-wraps automatically as you add or remove that marker.

## Test step

Test the website in VScode terminal by running:
    python3 -m http.server 8000 --directory public

## Push step

Simply git push, and the deploy.yml mirrors the code onto the website!
